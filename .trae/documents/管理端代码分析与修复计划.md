# 管理端功能重构计划（基于现有数据模型）

## 一、现有数据模型分析

### 支出相关模型
1. **PlatformTransaction** - 平台交易记录
   - type: RECHARGE, PAYOUT, REFUND
   - amount, balanceBefore, balanceAfter
   - relatedOrderNo - 关联订单号

2. **SettlementRecord** - 结算记录
   - goodsAmount - 货款（回收物品支付）
   - expressFee - 快递费
   - platformFee - 平台服务费

3. **Transaction** - 用户交易记录
   - type: ORDER_INCOME, WITHDRAWAL_* 等

### 快递相关模型
- **LogisticsProvider** - 物流服务商配置
  - name, code (jd, sf)
  - apiUrl, tenantId, appId, appSecret
  - isActive

## 二、功能调整方案

### 1. 移除骑手管理模块
- 删除 `src/app/(dashboard)/couriers/page.tsx`
- 删除 `src/services/courierService.ts`
- 更新侧边栏菜单

### 2. 新增支出管理模块
基于 `PlatformTransaction` 和 `SettlementRecord` 实现：

**支出类型：**
- 回收物品支付（PAYOUT）- 订单完成时向用户支付
- 快递费用支出

**页面功能：**
- 支出列表（按类型筛选：回收支付/快递费）
- 支出详情（关联订单信息）
- 支出统计图表（按日期、类型分类）
- 数据导出

### 3. 增强快递接入管理
基于现有 `LogisticsProvider` 模型：

**页面功能：**
- 快递公司列表（顺丰、京东等）
- 新增/编辑快递公司配置
- API密钥配置
- 启用/禁用状态管理
