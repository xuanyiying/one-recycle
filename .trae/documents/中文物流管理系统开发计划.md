# 中文物流管理系统与资金系统开发计划 (修订版)

感谢您的澄清。根据确认的需求（充值是指**租户/平台充值**，用于支付回收费用），我已调整开发计划如下：

## 阶段一：数据库架构设计 (Schema Design)

我们将修改 `server/prisma/schema.prisma` 以支持新功能：

1.  **新增 `LogisticsProvider` (物流服务商) 模型**：
    *   **用途**：配置快递公司（如京东、顺丰）的 API 接入信息。
    *   **字段**：
        *   `name`: 服务商名称
        *   `code`: 唯一编码 (如 `jd`, `sf`)
        *   `apiUrl`: 接口地址
        *   `tenantId`, `appId`, `appSecret`: 认证信息
        *   `config`: JSON 字段，存储自定义规则（如运费模板、配送范围）
        *   `isActive`: 启用状态

2.  **新增 `PlatformWallet` (平台/租户钱包) 模型**：
    *   **用途**：管理租户的资金池，用于支付用户的回收订单。
    *   **字段**：
        *   `balance`: 可用余额
        *   `frozenAmount`: 冻结金额（如有）
        *   `totalRecharge`: 累计充值
        *   `totalPayout`: 累计支出（支付给用户）
        *   `paymentPassword`: 支付密码（哈希存储，用于敏感操作验证）

3.  **新增 `PlatformTransaction` (平台交易记录) 模型**：
    *   **用途**：记录平台钱包的所有变动。
    *   **字段**：
        *   `type`: 交易类型 (`RECHARGE`-充值, `PAYOUT`-支付回收款, `REFUND`-退款)
        *   `amount`: 金额
        *   `balanceAfter`: 变动后余额
        *   `relatedOrderId`: 关联订单号（充值订单或回收订单）

4.  **新增 `RechargeOrder` (充值订单) 模型**：
    *   **用途**：记录租户发起的充值请求。
    *   **字段**：
        *   `orderNo`: 充值单号
        *   `amount`: 金额
        *   `paymentMethod`: 支付方式 (ALIPAY, WECHAT)
        *   `status`: 状态 (PENDING, SUCCESS, FAILED)

## 阶段二：后端核心逻辑实现 (NestJS)

1.  **物流模块 (`LogisticsModule`)**：
    *   **服务商管理**：实现对 `LogisticsProvider` 的增删改查。
    *   **运费计算**：提供统一接口，根据启用的服务商配置计算运费。

2.  **财务模块 (`FinanceModule`)**：
    *   **租户充值**：
        *   创建充值订单 -> 调起支付接口 -> 回调处理 -> 增加 `PlatformWallet` 余额 -> 记录 `PlatformTransaction`。
    *   **资金管理**：
        *   查询平台余额及流水。
        *   支付密码管理（设置/验证）。
    *   **支付回收款**（需与订单模块对接）：
        *   在用户回收订单结算时，从 `PlatformWallet` 扣款。需增加余额检查逻辑。

## 阶段三：管理后台前端开发 (Admin Web)

1.  **物流配置页面 (`/settings/logistics`)**：
    *   展示服务商列表，支持新增、编辑、启用/禁用。
    *   配置 API 密钥及运费规则。

2.  **资金管理页面 (`/finance`)**：
    *   **资产总览**：展示平台当前可用余额、累计支出等。
    *   **账户充值**：提供充值入口，支持自定义金额或选择套餐（如需），调用支付接口。
    *   **账单明细**：表格展示充值与支出记录，支持按时间筛选和导出。
