# OneRecycle 智能客服功能开发计划

## 一、项目概述

### 1.1 项目背景
为OneRecycle旧物回收小程序开发完整的智能客服功能模块，提升用户体验，降低人工客服成本，实现7x24小时在线服务。

### 1.2 核心目标
- 订单查询功能：支持订单号、手机号查询订单状态及详情
- 订单问题处理：取消、修改、退款、物流异常等
- 回收问题处理：预约查询、状态跟踪、价格异议、时间调整
- 智能问答与人工客服无缝切换
- 完整的工单管理系统

### 1.3 技术指标
- 响应时间 < 2秒
- 支持1000+并发用户
- 消息送达率 ≥ 99.9%
- AI自动回复准确率 ≥ 85%

   - WebSocket网关 (CustomerServiceGateway)

3. **管理后台** (`apps/admin-web/src/app/(dashboard)/customer/`)

## 三、数据库设计

### 3.1 新增数据表

```sql
-- 客服会话表
CREATE TABLE chat_sessions (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT REFERENCES users(id),
    agent_id BIGINT REFERENCES staffs(id),
    type VARCHAR(20) DEFAULT 'AUTO', -- AUTO:智能客服, MANUAL:人工客服
    status VARCHAR(20) DEFAULT 'ACTIVE', -- ACTIVE, WAITING, CLOSED
    topic VARCHAR(200),
    context JSONB, -- 会话上下文信息
    satisfaction_rating INTEGER CHECK (satisfaction_rating BETWEEN 1 AND 5),
    feedback TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    closed_at TIMESTAMP
);

-- 聊天消息表
CREATE TABLE chat_messages (
    id BIGSERIAL PRIMARY KEY,
    session_id BIGINT REFERENCES chat_sessions(id),
    sender_type VARCHAR(20) NOT NULL, -- USER, AGENT, SYSTEM, AI
    sender_id BIGINT,
    message_type VARCHAR(20) DEFAULT 'TEXT', -- TEXT, IMAGE, ORDER_CARD, TICKET_CARD
    content TEXT,
    media_url TEXT,
    extra_data JSONB, -- 订单卡片、工单卡片等额外数据
    status VARCHAR(20) DEFAULT 'SENT', -- SENDING, SENT, DELIVERED, READ
    is_read BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 知识库表
CREATE TABLE knowledge_base (
    id BIGSERIAL PRIMARY KEY,
    category VARCHAR(50) NOT NULL, -- ORDER, RECYCLE, PAYMENT, GENERAL
    question TEXT NOT NULL,
    answer TEXT NOT NULL,
    keywords TEXT[],
    intent VARCHAR(100), -- 意图识别标签
    priority INTEGER DEFAULT 0,
    is_active BOOLEAN DEFAULT TRUE,
    hit_count INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 客服工单表
CREATE TABLE service_tickets (
    id BIGSERIAL PRIMARY KEY,
    ticket_no VARCHAR(32) UNIQUE NOT NULL,
    session_id BIGINT REFERENCES chat_sessions(id),
    user_id BIGINT REFERENCES users(id),
    order_id BIGINT REFERENCES orders(id),
    type VARCHAR(50) NOT NULL, -- ORDER_CANCEL, ORDER_MODIFY, REFUND, LOGISTICS_ISSUE, RECYCLE_ISSUE, PRICE_DISPUTE
    priority VARCHAR(20) DEFAULT 'NORMAL', -- LOW, NORMAL, HIGH, URGENT
    status VARCHAR(20) DEFAULT 'PENDING', -- PENDING, PROCESSING, RESOLVED, CLOSED
    title VARCHAR(200) NOT NULL,
    description TEXT,
    attachments TEXT[],
    assigned_to BIGINT REFERENCES staffs(id),
    resolution TEXT,
    resolved_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 工单处理记录表
CREATE TABLE ticket_histories (
    id BIGSERIAL PRIMARY KEY,
    ticket_id BIGINT REFERENCES service_tickets(id),
    operator_id BIGINT REFERENCES staffs(id),
    action VARCHAR(50) NOT NULL, -- CREATE, ASSIGN, UPDATE, RESOLVE, CLOSE
    from_status VARCHAR(20),
    to_status VARCHAR(20),
    comment TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 快捷回复表
CREATE TABLE quick_replies (
    id BIGSERIAL PRIMARY KEY,
    agent_id BIGINT REFERENCES staffs(id),
    title VARCHAR(100) NOT NULL,
    content TEXT NOT NULL,
    category VARCHAR(50),
    sort_order INTEGER DEFAULT 0,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 客服统计表
CREATE TABLE customer_service_stats (
    id BIGSERIAL PRIMARY KEY,
    date DATE NOT NULL UNIQUE,
    total_sessions INTEGER DEFAULT 0,
    auto_sessions INTEGER DEFAULT 0,
    manual_sessions INTEGER DEFAULT 0,
    total_tickets INTEGER DEFAULT 0,
    resolved_tickets INTEGER DEFAULT 0,
    avg_response_time INTEGER, -- 毫秒
    avg_satisfaction DECIMAL(3,2),
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 索引
CREATE INDEX idx_chat_sessions_user_id ON chat_sessions(user_id);
CREATE INDEX idx_chat_sessions_agent_id ON chat_sessions(agent_id);
CREATE INDEX idx_chat_sessions_status ON chat_sessions(status);
CREATE INDEX idx_chat_messages_session_id ON chat_messages(session_id);
CREATE INDEX idx_chat_messages_created_at ON chat_messages(created_at);
CREATE INDEX idx_knowledge_base_category ON knowledge_base(category);
CREATE INDEX idx_knowledge_base_keywords ON knowledge_base USING GIN(keywords);
CREATE INDEX idx_service_tickets_user_id ON service_tickets(user_id);
CREATE INDEX idx_service_tickets_order_id ON service_tickets(order_id);
CREATE INDEX idx_service_tickets_status ON service_tickets(status);
CREATE INDEX idx_service_tickets_type ON service_tickets(type);
```

#### 4.1.1 意图识别
```typescript
enum UserIntent {
  // 订单相关
  ORDER_QUERY = 'ORDER_QUERY',           // 订单查询
  ORDER_CANCEL = 'ORDER_CANCEL',         // 订单取消
  ORDER_MODIFY = 'ORDER_MODIFY',         // 订单修改
  ORDER_REFUND = 'ORDER_REFUND',         // 退款申请
  LOGISTICS_QUERY = 'LOGISTICS_QUERY',   // 物流查询
  LOGISTICS_ISSUE = 'LOGISTICS_ISSUE',   // 物流异常
  
  // 回收相关
  RECYCLE_QUERY = 'RECYCLE_QUERY',       // 回收预约查询
  RECYCLE_STATUS = 'RECYCLE_STATUS',     // 回收状态
  RECYCLE_RESCHEDULE = 'RECYCLE_RESCHEDULE', // 时间调整
  PRICE_INQUIRY = 'PRICE_INQUIRY',       // 价格咨询
  PRICE_DISPUTE = 'PRICE_DISPUTE',       // 价格异议
  
  // 通用
  GENERAL_QUESTION = 'GENERAL_QUESTION', // 一般问题
  TRANSFER_AGENT = 'TRANSFER_AGENT',     // 转人工
  UNKNOWN = 'UNKNOWN'                    // 未识别
}
```

#### 4.1.2 AI回复流程
```
用户消息 → 意图识别 → 实体提取 → 业务处理 → 生成回复
    │           │           │           │           │
    │           │           │           │           └─ 返回给用户
    │           │           │           └─ 调用订单/回收服务
    │           │           └─ 提取订单号、手机号等
    │           └─ 关键词匹配/AI分类
    └─ 接收用户输入
```

#### 4.1.3 支持的查询类型
1. **订单查询**
   - "查询我的订单"
   - "订单号123456789"
   - "手机号138xxxx8888的订单"
   - "最近的订单状态"

2. **订单问题处理**
   - "取消订单"
   - "修改收货地址"
   - "申请退款"
   - "物流异常反馈"

3. **回收问题处理**
   - "查询回收预约"
   - "修改上门时间"
   - "回收价格异议"
   - "回收物品状态"
