# OneRecycle 上线前 Review 任务清单

## Task 1: 服务端上线 Review
**描述**: 对 NestJS 服务端进行全面代码审查、测试验证和安全检查

- [ ] SubTask 1.1: 代码质量检查
  - 执行 `npm run lint` 检查 ESLint 错误
  - 执行 `npm run typecheck` 检查 TypeScript 类型
  - 检查代码风格一致性

- [ ] SubTask 1.2: 测试覆盖率验证
  - 执行 `npm run test:cov:unit` 运行单元测试
  - 验证覆盖率 >= 90%
  - 确认 338/338 测试用例通过

- [ ] SubTask 1.3: 安全漏洞扫描
  - 执行 `npm audit` 检查依赖安全
  - 检查敏感信息是否硬编码
  - 验证 JWT Secret 强度

- [ ] SubTask 1.4: 数据库迁移验证
  - 执行 `npx prisma migrate deploy`
  - 验证所有表和索引已创建
  - 检查种子数据导入

- [ ] SubTask 1.5: 生产环境配置检查
  - 检查 `.env.production` 配置完整性
  - 验证数据库连接字符串
  - 验证 Redis 配置
  - 验证支付配置（微信、支付宝）
  - 验证 OSS 配置（腾讯云 COS）
