# OneRecycle - 旧书旧衣物回收小程序 UI/UX 设计文档

本文档详细定义了针对中国市场的 "OneRecycle" 小程序及其管理后台的用户体验设计。项目专注于旧书与旧衣物的回收，集成京东物流，并包含完善的积分激励系统。

## 1. 项目概述 (Overview)

- **核心业务**: 旧书、旧衣物上门回收。
- **目标用户**: 关注环保的年轻群体及有家庭清理需求的中老年群体。
- **关键特性**: 京东快递上门、积分兑换/提现、可视化环保成就。
- **设计风格**: 环保自然、清晰易用（兼顾中老年用户体验）。

## 2. 核心用户流程 (User Flow)

### 2.1 预约回收与订单闭环

```mermaid
graph TD
    A[用户打开小程序] --> B{是否登录?};
    B -- 否 --> C[微信一键授权登录];
    C --> D[首页];
    B -- 是 --> D;

    D --> E[选择回收品类: 旧书 / 旧衣物];
    E --> F[智能估价器 (可选)];
    E --> G[填写预约信息];
    
    subgraph "预约信息填写"
        G1[上传物品照片] 
        G2[选择/自动定位地址]
        G3[选择上门时间 (精确到小时)]
        G --> G1 --> G2 --> G3;
    end

    G3 --> H[预估积分展示];
    H --> I[提交订单];
    
    I --> J{系统派单 (对接京东)};
    J -- 成功 --> K[状态: 待接单/已接单];
    J -- 异常 --> K1[人工客服介入];

    K --> L[快递员上门揽收];
    L --> M[称重/核验];
    M --> N[更新实际重量/数量];
    N --> O[用户确认最终积分];
    O --> P[订单完成 & 积分到账];

    P --> Q[查看积分钱包/提现];
```

### 2.2 积分提现流程

```mermaid
graph TD
    A[个人中心] --> B[积分钱包];
    B --> C[点击提现];
    C --> D{是否绑定微信支付?};
    D -- 否 --> E[引导实名认证/绑定];
    D -- 是 --> F[输入提现金额];
    F --> G[确认提现];
    G --> H[系统审核];
    H --> I[提现到账 (微信零钱)];
```

## 3. 功能模块与原型设计 (Wireframes)

### 3.1 小程序端 (Mini Program)

#### 3.1.1 首页 (Home)
简洁直观，强调两大核心品类。

- **顶部导航**: 
  - `[定位: 北京市 v]` `[天气/环保提示]`
- **核心操作区 (大卡片)**:
  - **左侧**: `[旧书回收]` (配图: 整齐的书籍, 文案: 知识循环, 0.8元/kg)
  - **右侧**: `[旧衣回收]` (配图: 叠好的衣物, 文案: 衣旧情深, 0.5元/kg)
- **功能栏**:
  - `[预约记录]` `[积分商城]` `[环保榜单]` `[服务说明]`
- **活动Banner**:
  - `[轮播图: 新用户首单加赠100积分]`
- **底部导航 (Tab)**:
  - `[首页]` `[订单]` `[我的]`

#### 3.1.2 预约下单页 (Reservation)
减少输入成本，适配中老年用户（大字体，清晰指引）。

- **品类确认**: `[图标] 旧书回收` (可切换)
- **物品信息**:
  - `预估重量`: `[ 5-10kg ]` `[ 10-20kg ]` `[ 20kg+ ]` (点击块状选择)
  - `物品照片`: `[+] 添加照片` (自动识别引导: 请拍摄物品堆放全景)
- **上门信息**:
  - `地址`: `[图标] 自动定位地址... [修改]` (大字号显示)
  - `时间`: `[日期选择] [时间段选择]` (京东物流时间段: 09:00-11:00, 11:00-13:00 等)
- **底部栏**:
  - 左侧: `预估获得: ~150 积分`
  - 右侧: `[立即预约]` (大按钮, 绿色背景)

#### 3.1.3 订单状态/追踪页 (Order Tracking)
集成京东物流状态。

- **状态头**:
  - `[已接单]` (京东小哥正在赶来)
  - `[预计上门]: 今日 14:30`
- **物流卡片**:
  - `[京东Logo]` `快递员: 王师傅` `[电话图标]`
  - `物流单号: JDV00123456789` `[复制]`
  - `[地图组件: 显示快递员位置/轨迹]` (可选)
- **进度轴**:
  - `● 已下单`
  - `● 快递员已接单 (10:05)`
  - `○ 待揽收`
  - `○ 待入库核验`
  - `○ 完成`

#### 3.1.4 积分钱包与提现 (Wallet)

- **资产概览**:
  - `当前积分: 2,450` `(≈ ¥24.50)`
  - `[立即提现]` `[兑换好物]`
- **收支明细 (List)**:
  - `旧书回收 (+300积分)` `2025-10-01`
  - `提现到微信 (-1000积分)` `2025-09-28`
- **提现弹窗**:
  - `提现金额`: `[输入框: ¥ 10]`
  - `费率提示`: `免手续费`
  - `[确认提现]` (调用微信支付企业付款接口)

### 3.2 管理后台 (Admin Dashboard)

#### 3.2.1 数据概览 (Dashboard)
- **统计卡片**: `今日回收量(kg)`, `新增用户`, `今日订单数`, `累计发放积分`
- **图表区**:
  - `回收趋势图` (折线图: 书籍 vs 衣物)
  - `区域热力图` (地图: 订单密集区域)
  - `用户增长曲线`

#### 3.2.2 订单管理 (Order Mgmt)
- **筛选**: `订单状态` (含京东物流状态), `异常标记`, `下单时间`
- **列表项**: `订单号`, `用户`, `品类`, `预估/实重`, `京东单号`, `状态`, `操作`
- **物流异常处理**:
  - 标记为 `[揽收失败]`, `[拒收]`, `[重量不符]`
  - 操作: `[重新派单]`, `[联系用户]`

#### 3.2.3 积分与财务 (Points & Finance)
- **提现审核**: `待审核列表`, `自动打款记录`
- **积分配置**: 设置不同品类的 `积分/kg` 兑换比例

## 4. 物流配送设计 (Logistics Integration)

### 4.1 UI 反馈机制
- **下单时**: 实时校验地址是否在揽收范围内。
  - *不在范围内*: 弹窗提示 "抱歉，该区域暂不支持上门回收"，推荐附近回收点。
- **揽收中**: 同步物流轨迹节点（接单、揽收、运输、签收）。
- **取消**: 用户取消订单时，同步调用物流取消接口，并反馈结果（"快递员已出发，请电话联系拦截"）。

### 4.2 异常处理 UI
- **快递员无法联系**: 提示用户 "快递员无法联系到您，请确认电话畅通"，提供 [修改联系方式] 入口。
- **超重/体积过大**: 快递员录入异常后，用户端展示 "物品超规需额外处理"，需用户 [确认] 或 [取消]。

## 5. 视觉设计规范 (Visual Design)

### 5.1 色彩体系 (Color System)
采用大地色系与环保绿，传递可持续发展理念。

- **品牌主色 (Primary)**:
  - `森林绿 #2E7D32`: 用于主按钮、图标、强调文字。象征自然、生命。
  - `大地褐 #795548`: 用于辅助图形、次级按钮。象征土壤、再生。
- **功能色**:
  - `品牌蓝 #007AFF`: 用于物流相关标识，保持品牌认知。
  - `微信绿 #07C160`: 用于支付、提现成功状态。
  - `警示黄 #FBC02D`: 用于状态等待、重要提示。
- **背景色**:
  - `米白色 #F5F5F0`: 替代纯白背景，更护眼，更有纸张质感。

### 5.2 字体与排版 (Typography)
特别优化**适老化**设计。

- **字体**: PingFang SC (iOS) / Noto Sans SC (Android)。
- **层级**:
  - `大标题`: 24px (用于关键数字、状态)
  - `标题`: 18px (加粗)
  - `正文`: 16px (常规) - *比标准设计大2px*
  - `辅助`: 14px
- **对比度**: 确保文字与背景对比度至少 4.5:1 (WCAG AA标准)。

### 5.3 组件规范 (Components)
- **按钮**:
  - 高度 `48px` (更大点击区域)。
  - 圆角 `8px`。
- **卡片**:
  - 投影 `0 4px 12px rgba(46, 125, 50, 0.08)` (绿色系投影)。
  - 圆角 `12px`。
- **图片**:
  - 全局采用圆角处理。
  - 上传图片支持 `点击预览` 和 `一键删除`。

### 5.4 交互反馈 (Interaction)
- **加载状态**: 使用 "循环箭头" 或 "小树苗生长" 动画替代系统菊花图。
- **操作成功**: 弹出 Toast 提示，并伴随轻微震动反馈 (Taptic Engine)。
- **积分动效**: 积分增加时，数字滚动上升，并有金币/树叶飞入钱包的动画。
