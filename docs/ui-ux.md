# OneRecycle - UI/UX 设计文档

本文档定义了 "OneRecycle" 小程序的核心用户流程、页面线框图和基础设计规范。

## 1. 用户流程 (User Flow)

核心用户旅程：从授权登录到完成回收订单。

```mermaid
graph TD
    A[Start] --> B{用户是否已登录?};
    B -- 否 --> C[引导授权登录页面];
    C -- 授权成功 --> D[首页];
    B -- 是 --> D;

    D --> E[点击 "一键回收"];
    E --> F{有无默认地址?};
    F -- 无 --> G[地址选择/新建页面];
    G -- 保存地址 --> H[回收物信息填写页];
    F -- 有 --> H;

    H -- 填写物品分类、照片、预估重量 --> I[预约上门时间页];
    I -- 选择时间 --> J[订单确认页];
    J -- 显示地址、物品、时间、预估价 --> K[提交订单];
    K -- 成功 --> L[下单成功/待派单页];
    L --> M{订单状态变更};

    M -- 快递员接单 --> N[状态: 待上门];
    M -- 快递员完成回收 --> O[状态: 待确认/结算];
    O --> P{需要支付?};
    P -- 是 --> Q[支付页面];
    Q -- 支付成功 --> R[状态: 已完成];
    P -- 否 (平台付款) --> R;

    R --> S[评价页面 (可选)];
    S --> T[End];
    R --> T;

    subgraph "随时可访问"
        U[我的订单]
        V[个人中心]
    end
    D --> U;
    D --> V;
```

## 2. 页面线框图 (Wireframes)

以下是关键页面的文本化线框图描述。

### 2.1. 首页 (Home)

-   **顶部区域**:
    -   `[Logo]` `[当前城市 v]`
    -   `[搜索框: 搜索回收品类]`
-   **Banner 区域**:
    -   `[轮播图: 环保活动、高价回收品类]`
-   **核心功能入口**:
    -   `[大按钮: 一键预约回收]`
-   **品类导航**:
    -   `[Icon+文字: 手机数码]` `[Icon+文字: 家用电器]` `[Icon+文字: 旧衣物]` `[Icon+文字: 查看更多]`
-   **信息流/文章**:
    -   `[卡片: 环保知识、回收动态]`
-   **底部导航栏 (Tab Bar)**:
    -   `[首页]` `[分类]` `[订单]` `[我的]` (高亮: 首页)

### 2.2. 回收物信息填写页 (Item Form)

-   **导航栏**: `[< 返回]` `[填写回收信息]`
-   **地址区域**:
    -   `[Icon] [张三, 138****1234]`
    -   `[广东省深圳市南山区...]` `[修改 >]`
-   **物品列表**:
    -   `[+] [添加回收物品]`
    -   **物品卡片1**:

    -   `备注: [点击填写]`

### 2.4. 订单详情页 (Order Details)

-   **顶部状态区域**:
    -   `[状态Icon: 待上门]` `[状态文字: 快递员正在路上]`

-   **快递员信息**:
    -   `[头像] [李师傅]` `[电话按钮]`
-   **订单时间轴 (Timeline)**:
    -   `[已完成] 订单已提交 (10-05 12:30)`

### 2.5. 管理后台 - 订单管理页 (Admin - Order Management)

-   **面包屑导航**: `[首页] / [订单管理]`
-   **筛选/搜索区域**:

-   **操作按钮**:

-   **数据表格 (Table)**:
    -   **列**: `[ ]` (复选框), `订单号`, `用户`, `地址`, `预约时间`, `状态`, `结算金额`, `快递员`, `创建时间`, `操作`

    -   **操作列按钮**: `[详情]`, `[派单]`, `[修改价格]`, `[取消]`
-   **分页**:
    -   `[<] [1] [2] [3] ... [>]` `共 128 条`

## 3. 设计规范 (Design System)

-   **色彩体系**:
    -   **主色 (Primary)**: `#00B894` (绿色，代表环保、生机)。用于核心操作按钮、导航高亮等。
    -   **辅助色 (Accent)**: `#FFC107` (黄色，用于提醒、优惠、金额等)。
    -   **中性色 (Neutral)**:
        -   `#2D3436` (深灰，用于主要文字)。
        -   `#636E72` (中灰，用于次要文字、图标)。
        -   `#F5F6FA` (浅灰，用于页面背景)。
    -   **状态色**:
        -   `#0984E3` (蓝色，信息)。
        -   `#D63031` (红色，错误、警告)。
-   **字体规范**:
    -   **中文字体**: PingFang SC (iOS), Noto Sans SC (Android)。
    -   **英文字体**: Helvetica, Roboto。
    -   **字号**: 标题 (18px, 加粗), 正文 (16px), 辅助信息 (14px), 标签 (12px)。
-   **组件风格**:
    -   **按钮**: 圆角矩形。主按钮填充主色，次要按钮线框或灰色填充。
    -   **卡片**: 使用轻微的圆角和阴影，创造层次感。
    -   **图标**: 线性、简约风格，保持一致性。
