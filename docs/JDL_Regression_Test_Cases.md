
## 7. 回归测试用例 (Regression Test Cases)

### 7.1 基础功能测试
| ID | 用例名称 | 前置条件 | 操作步骤 | 预期结果 |
|---|---|---|---|---|
| TC01 | 地址围栏校验-支持区域 | 无 | 调用 `range.check`，地址为"北京市朝阳区..." | 返回 `isSupport: true` |
| TC02 | 地址围栏校验-不支持区域 | 无 | 调用 `range.check`，地址为"西藏阿里地区..." | 返回 `isSupport: false` |
| TC03 | 正常下单流程 | 地址校验通过 | 调用 `order.add`，传入有效手机号和地址 | 返回 `jdOrderId`，无报错 |
| TC04 | 取消订单 | 订单已创建且未揽收 | 调用 `order.cancel` | 返回成功，JDL后台状态同步更新 |
