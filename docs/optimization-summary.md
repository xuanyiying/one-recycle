## 🗄️ 一、数据模型优化

### 1.1 分类服务优化

#### ✅ 优化内容

**Category 模型增强**:

- 新增 `code` 字段: 分类唯一编码，便于前端识别
- 新增 `parentId` 和 `level`: 支持多级分类结构
- 新增 `iconType`: 支持图片、字体图标、Emoji三种类型
- 新增 `coverImage`: 分类封面图
- 新增 `isHot`: 标记热门分类
- 新增 `unit`: 计量单位（kg、件、个等）

**新增 PricingRule 模型** (计费策略):

```prisma
- 支持固定单价、阶梯定价、品质定价、动态定价
- 支持区域差异化定价
- 阶梯定价配置: tierConfig (JSON)
- 品质系数配置: qualityFactor (JSON)
- 最小/最大重量限制
- 生效时间范围控制
```

**新增 RecyclableItem 模型** (可回收物品):

```prisma
- 详细物品信息: 名称、品牌、型号
- 参考图片数组
- 标签系统 (热门、高价等)
- 平均回收价和价格区间
- 排序和启用控制
```

#### 💡 设计亮点

- **灵活定价**: 支持多种定价策略，适应不同品类和市场变化
- **多级分类**: 支持"手机数码 > iPhone > iPhone 13 Pro"等层级结构
- **物品库**: 预定义常见回收物品，提升用户体验和估价准确性

---

### 1.2 支付与提现模型优化

#### ✅ 优化内容

**Payment 模型增强**:

- 新增 `userId`: 关联用户
- 新增 `paymentType`: 区分订单服务费、押金等类型
- 新增 `paidAt`: 支付完成时间
- 新增 `remark`: 备注说明

**新增 UserAccount 模型** (用户账户):

```prisma
- balance: 可用余额
- frozenAmount: 冻结金额
- totalIncome: 累计收入
- totalWithdraw: 累计提现
```

**新增 AccountTransaction 模型** (账户流水):

```prisma
- 记录所有资金变动
- 交易前后余额快照
- 关联订单和提现记录
- 详细交易描述
```

**新增 Withdrawal 模型** (提现记录):

```prisma
- 支持微信、支付宝、银行卡三种提现方式
- 手续费计算
- 完整的状态流转: 待审核 → 已审核 → 处理中 → 已完成
- 失败原因记录
- 第三方交易号追踪
```

#### 💡 设计亮点

- **完整的资金流**: 从订单收入到提现全流程追踪
- **账户安全**: 冻结金额机制，防止异常提现
- **多渠道提现**: 支持主流支付方式
- **审核机制**: 提现需要审核，保障资金安全

---

### 1.3 订单物品模型优化

#### ✅ 优化内容

**OrderItem 模型增强**:

- 新增 `categoryId` 和 `categoryName`: 关联分类并保存快照
- 新增 `itemName`, `brand`, `model`: 详细物品信息
- 新增 `quality` 枚举: 物品成色（全新、良好、一般、较差）
- 新增 `images` 数组: 物品照片
- 新增 `unit`: 计量单位
- 新增 `remark`: 物品备注
- 新增 `updatedAt`: 更新时间

#### 💡 设计亮点

- **数据快照**: 保存分类名称，防止分类修改影响历史订单
- **成色评估**: 支持物品品质评估，影响定价
- **图片证据**: 保存物品照片，便于纠纷处理
