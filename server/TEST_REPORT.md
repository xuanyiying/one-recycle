## 九、应急回滚方案

### 9.1 数据库回滚

```bash
# 恢复数据库备份
pg_restore -h localhost -U postgres -d one_recycle backup_file.dump
```

### 9.2 版本回退

```bash
# 回退到上一个版本
git checkout <previous_commit_hash>
npm run build
pm2 restart all
```

### 9.3 紧急停服

```bash
# 停止所有服务
pm2 stop all
```
